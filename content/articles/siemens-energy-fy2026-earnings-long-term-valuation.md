**西门子能源的燃机与电网增长已经转化为利润，长期持有的经营依据比上季度更充分。约129欧元的股价也比上篇约154欧元更有吸引力，但目前仍需要为风电修复、订单转化、扩产和估值波动留出余地。**

本报告对照[上季度Q3 FY2026深度分析](/articles/siemens-energy-q3-fy2026-deep-analysis)，重新检验当时的判断，并以11月11日披露的Q4及FY2026初步全年业绩、FY2027指引和FY2030目标为依据更新估值。基准两法参考约145欧元，主要参考区间为140—150欧元；相对128.74欧元的价格基准，基准折让约11%，尚不足以称为厚安全边际。

证券为Xetra上市的Siemens Energy AG，行情代码ENR.DE。除另行标注，财务金额均为**亿欧元**，每股价格及EPS为欧元。FY2026截至2026年9月30日，Q4为7—9月，不能与日历年第三季度混用。

## 从上季度到现在，哪些判断得到验证

上篇认为，公司经营质量明显改善，但约154欧元的股价已经反映较高预期；后续需要验证全年利润、Gamesa盈亏平衡、现金流质量及新的中期目标。三个多月后，经营和价格发生了两个方向的变化：利润继续兑现，价格基准却较上篇153.94欧元下降约16.4%。估值吸引力因此改善，但不能仅凭跌幅推导低估。

| 上篇需要验证的事项 | 本次实际结果 | 对判断的影响 |
| --- | --- | --- |
| Q4集团利润率可能从Q3的14.2%回归低双位数 | Q4特殊项前利润率12.0% | 季度正常化发生，未构成主业失速 |
| 全年净利润约40亿能否兑现 | 集团净利润41.29亿 | 盈利目标实现 |

| Gamesa能否全年盈亏平衡 | 特殊项前盈利0.08亿，税前现金仍流出15.80亿 | 利润目标实现，现金修复继续等待 |
| 燃机、电网的高质量积压能否转为收入和利润 | 两业务全年特殊项前利润合计50.45亿，FY27指引继续改善 | 核心投资逻辑增强 |
| 新中期目标能否提高增长上限 | FY30目标为收入超过700亿、特殊项前率20—22% | 增长路径延长，执行门槛同步提高 |

上篇用于推导Q4的低税率预期也需更新。最终全年所得税费用13.18亿、税前利润54.47亿，账面税率约24.2%，不能继续沿用全年低于20%的假设。全年净利润达标，主要仍要由经营利润改善来解释。

上篇强调的矛盾仍然有效：高增长能否持续转化为每股价值，以及盈利增长能否抵消市场给出更低估值倍数的影响。新的财报改善了这个问题的经营端，股价回落改善了价格端，但两项都没有消除风险。

## 赚钱机制：燃机服务与电网交付支撑价值

西门子能源制造燃气轮机、发电机及相关系统，也提供变压器、开关设备和高压输电技术。燃机设备安装后，维护、检修、升级和零部件需求会延续多年。电网业务则依靠设计、制造、认证、工程和供应链能力，把长周期订单转为交付和现金。

客户购买可靠性和按规格交付的能力。设备失效、工期延误或停机的损失，往往高于最初节省的采购成本。已安装机组、服务经验和客户关系有助于形成持续业务。不过，新项目仍需竞争，供应链和项目执行仍可能侵蚀利润。

因此，燃机短缺和电网投资增长提供了有利环境，护城河能否产生股东价值，还要看新增订单价格、交付成本、装机后的服务转化以及资本投入回报。

## 分部复盘：增长最强的两项业务与尚未完成的风电修复

| 业务 | FY26收入 | 特殊项前利润 | 利润率 | 税前自由现金流 |
| --- | ---: | ---: | ---: | ---: |
| Gas Services燃机 | 145.03 | 23.85 | 16.4% | 64.48 |
| Grid Technologies电网 | 141.06 | 26.60 | 18.9% | 40.95 |
| Transformation of Industry工业转型 | 58.47 | 7.07 | 12.1% | 6.94 |
| Siemens Gamesa风电 | 105.62 | 0.08 | 0.1% | -15.80 |

分部合计与集团之间有抵销和总部等调节，不能把分部现金流相加直接当作普通股股东收益。

**燃机的关键，是新机盈利改善与未来服务收入接续。** 全年订单可比增长45.9%，积压达到740亿。高价订单逐步交付、规模提升和执行改善推动利润；新装机扩大未来服务基础。下一年收入可比增长24—26%、利润率18—20%的指引，表明管理层预计改善仍将继续。

但新订单时点值得关注。Q4新机订单约2GW，52台均为小／中型机组，没有大型机组，预订转正式订单也为零。集团季度订单低于财报前预期约4.2%，强利润并不代表所有订单数据都超预期。

年末燃机承诺合计104GW，组成是**65GW正式积压加39GW产能预订协议**。公司预计39GW预订在FY2027转为正式合同。预订有经济约束和收费价值，但在完成转化前，不能把104GW全部写成已签正式设备订单。后续若连续几个季度延迟，应重估增长和现金安排。

**电网业务的盈利已相当强，单季订单回落需要结合大项目基数。** 全年订单可比增长14.5%，积压520亿；FY27收入可比增长22—24%、利润率21—23%的指引进一步提高。Q4订单可比下降19.3%，去年同期包含两个大型HVDC项目；本季订单／收入仍为1.30，全年订单和积压也在增长。单个季度的下降不足以证明需求见顶，但仍需跟踪新项目定价与产能利用。

**Gamesa完成了全年特殊项前盈亏平衡，现金流修复尚需时间。** 全年特殊项前盈利只有800万欧元，计特殊项后的Profit亏损1.76亿、IFRS EBIT亏损2.24亿。全年税前自由现金流流出15.80亿，虽然Q4已流入1.36亿。

风电全年订单可比下降31.1%；Q4因大单增长148.1%，不能据此描述为全年订单高增长。FY27收入还预计下降1—3%，利润率0—2%。公司目标FY28经营现金转正、FY30利润率8—10%，修复路径存在，但新的质保、维修和项目损失仍可能使它反复。

工业转型业务全年利润率12.1%，相较Q3的14.3%回归正常；这也验证了上篇对有利项目时点效应的提醒。公司计划分离该业务，并最终保留有意义的少数股权。交易形式、税费和出表范围确定前，不能同时保留全部原利润，再免费加出售所得及保留股权价值。[分部结果与战略安排](https://assets.siemens-energy.com/dam/991522b0-f8bd-4c08-bc2a-b4ff00538589/2026-11-11_Q4_Analyst_presentation_final_-pdf_Original%20file.pdf)。

## FY2027：主营指引较强，净利润需要拆开费用和税

| FY2027公司指引 | 收入可比增长 | 特殊项前利润率 |
| --- | ---: | ---: |
| 集团 | 14—16% | 14—16% |
| Gas Services | 24—26% | 18—20% |
| Grid Technologies | 22—24% | 21—23% |
| 工业转型 | 0—2% | 11—13% |
| Gamesa | -3至-1% | 0—2% |

集团另预计净利润约50亿、税前自由现金流约100亿。约85%的下一年收入已由积压订单覆盖，收入可见性较高；覆盖仍需要交付、验收和客户履约。

财报前一致预期为FY27收入503.14亿、特殊项前利润74.10亿，对应利润率约14.7%。公司新利润率指引覆盖这一水平。净利润约50亿却低于原预期55.32亿约9.6%，原因需要继续拆解。

公司在分析师材料第39页列出的假设包括：

- 特殊项约负7亿，主要涉及Omterra改名及工业转型业务拆分；原一致预期只计约负1.01亿。
- 账面税率约27%，包含拆分相关税项；原一致预期约24.6%。
- 财务结果约正5亿，少数股东利润约4亿。
- 资本开支达到收入的5—6%，高于FY26约4.5%。

这说明净利润预期差主要应从特殊费用和税率解释，不能只看净利润一行就认定燃机、电网主营转弱。同时，改名、拆分和税费会消耗股东价值，不能因为列为特殊项就全部忽略；Gamesa的FY27收入及利润率指引也偏弱。

另一个重要口径是：**50亿为集团净利润，不是归母净利润。** 扣约4亿少数股东利润，归母约46亿。以本报告8.55亿估值稀释股数计算，FY27 EPS约5.38欧元，价格基准对应约23.9倍PE。

本研究的正常化基准只加回7亿特殊项中的5亿，保留部分持续费用；同时将财务收益降至2亿、税率正常化至25%。以十亿欧元表示，利润桥为：

`5 ÷ (1−27%) − 0.5 = 报告口径隐含EBIT 6.3493`

`6.3493 + 非经常特殊费用加回0.5 = 正常化EBIT 6.8493`

`(6.8493 + 财务收益0.2) × (1−25%) − 少数利润0.4 = 正常化归母4.8870`

正常化EPS约5.72欧元，对应约22.5倍PE。这是研究口径，非公司公布的调整EPS；PPA摊销已包含在反推EBIT中，不重复扣。原来的FY27一致预期EPS6.23欧元，也不能冒称财报后的最新共识。

## 从利润到现金，再到普通股股东

FY26经营现金流99.58亿，现金资本开支19.70亿，税后自由现金流79.88亿；加回已付所得税8.11亿，对应公司税前自由现金流87.99亿。

现金真实流入公司，预付款也降低融资需要。但客户先付款，企业仍需生产并交付设备，不能把这些现金全部当作已完成创造的股东收益。

| FY26主要营运资金现金变化 | 流入／流出 |
| --- | ---: |
| 合同负债 | +58.12 |
| 合同资产 | -12.88 |
| 库存 | -13.99 |
| 应收款 | -10.32 |
| 应付款 | +3.58 |
| 五项合计 | **+24.51** |

只减去58.12亿预付款、同时保留配套库存和应收占用，会低估当期现金创造；完全忽略这笔24.51亿净流入，又会高估可持续收益。

剔除五项营运资金净流入后，税后FCF约55.37亿；再扣融资现金流中的租赁4.61亿、利息1.67亿和少数股息2.27亿，约为**46.82亿**。这仍含其他资产负债时点变化约10.69亿，也包含扩产投入及税款时点，不能把它当作精确所有者收益或永久现金基数。

FY27约100亿税前FCF同样需要向下衔接：

| FY27现金用途，公司估计 | 亿欧元 |
| --- | ---: |
| 税前自由现金流 | 100 |
| 现金税 | -13 |
| 利息／担保支付 | -2 |
| 少数股东股息 | -3 |
| 融资现金流中的租赁支付 | -6 |
| 普通股分红、回购前余额 | **76** |
| 普通股股息 | -19 |
| 回购，含员工股份计划用股 | -30 |
| 剩余，尚未计额外并购等 | **27** |

资本开支已在FCF中扣除，不能重复再扣。100亿税前FCF也不能直接除市值，称为普通股股东可持续收益率。

9月底现金111.56亿、报表Debt29.75亿，原始净现金81.81亿，公司调整净现金约78亿。估值只认可原始净现金的一半，为交付、扩产、现金时点和资本配置保留余地；这是研究假设，不是公司披露50%现金受限。合同负债也没有被再次全部当作金融债务扣除。完整债务、租赁、担保及现金限制仍待年报补充。

拟分红每股2.30欧元，高于上一年的0.70欧元，按价格基准股息率约1.8%；需股东大会批准、在FY27支付。新增回购上限90亿延续至FY30，叠加原计划，并非下一年一次执行90亿。每年回购安排还包含员工计划用股，应跟踪净股数而非只看回购金额。[资本配置与FY27现金假设](https://assets.siemens-energy.com/dam/991522b0-f8bd-4c08-bc2a-b4ff00538589/2026-11-11_Q4_Analyst_presentation_final_-pdf_Original%20file.pdf)。

## 估值：价值参考约140—150欧元，主要风险在盈利和倍数

本报告以正常化归母利润乘前瞻PE为主要方法，用EBIT乘EV/EBIT交叉检查。两法共用盈利假设，不能视为独立的现金流验证；没有把预付款高峰建立为永续DCF。

为近似日历2027，采用75% FY2027加25% FY2028，季度季节性未知。FY27使用前述正常化利润桥；FY28研究假设如下，并非公司指引：收入565亿、特殊项前利润率17%、PPA2亿、持续特殊费用1.5亿、净财务收益2亿、税率25%、少数股东利润4.5亿。

由此得到近似日历2027正常化EBIT74.51亿、归母53.26亿、EPS约6.23欧元。这里的6.23是本模型日历近似值，与旧FY27共识数值接近，期间及口径不同。

| 基准估值桥 | 采用值／结果 |
| --- | ---: |
| 正常化归母53.26亿 × 24倍PE | 股权价值1,278.13亿 |
| 正常化EBIT74.51亿 × 17倍EV/EBIT | 企业价值1,266.63亿 |
| 企业价值加认可净现金 | +40.91亿 |
| 扣养老金准备 | -3.82亿 |
| 扣少数股东权益估值 | -99.00亿 |
| EV法股权价值 | 1,204.71亿 |
| 估值稀释股数 | 8.55亿股 |
| PE法每股价值 | 149.49欧元 |
| EV法每股价值 | 140.90欧元 |
| 两法均值，仅作基准锚 | **145.20欧元** |

8.55亿股是依据Q4归母和四舍五入后的稀释EPS推得的审慎近似，不是精确实时流通股数，亦未提前全计入未来回购。PE法利润已含财务收益，不额外再加一笔净现金。

少数权益尤其需要说明。EV使用完整集团EBIT，其中部分盈利属于其他股东，因此要从企业价值扣除他们的经济权益。本报告用近似日历少数盈利4.125亿乘同情景24倍PE，估算99亿欧元；这是模型假设，不是已披露市值或新债务。PE法已经使用归母利润，不再扣一遍。

若只扣账面少数权益5.10亿，EV交叉值约151.88欧元，两法平均约150.69欧元。两种处理带来约5.49欧元差异，说明少数权益方法影响价值锚，不能把这一差异都归因于公司经营变化。本报告采用经济权益估计后的145欧元，更适合保留审慎余地；它也不是逐项市场重估的分部加总。

| 情景 | 关键研究假设 | PE／EV交叉范围 | 两法中值 |
| --- | --- | ---: | ---: |
| 悲观 | FY27集团净利42亿；FY28收入520亿、率14%；PE20、EV14 | 93—95欧元 | 94欧元 |
| 基准 | FY27集团净利约50亿；FY28收入565亿、率17%；PE24、EV17 | 141—149欧元 | 145欧元 |
| 乐观 | FY27集团净利56亿；FY28收入590亿、率18.5%；PE28、EV20 | 188—204欧元 | 196欧元 |

给三种情景主观权重30%／50%／20%，参考约140欧元。权重未经统计校准，只用于呈现风险取舍。相对128.74欧元，基准折让约11.3%、上涨空间约12.8%；主观情景参考折让约8.1%。

折让的定义为`（估值−价格）÷估值`，上涨空间的分母为价格。两者都是给定假设下的价差，盈利或倍数改变，价差也会改变。悲观情景意味着仍有约27%下行，且未覆盖所有极端质量事故或流动性冲击。

| 敏感性，其他条件按基准保留 | 每股参考 |
| --- | ---: |
| PE降至20倍、EV/EBIT降至14倍 | 约121欧元 |
| 正常化EBIT下降10%，保留基准税率、财务收益及少数利润 | 约130欧元 |
| FY27不加回特殊项，不调整该年税率及财务结果 | 约138欧元 |
| 净现金认可比例从0%到100% | 约143—148欧元 |

当前最重要的估值风险是利润兑现及市场给予的倍数。即使订单没有取消，长期利率维持较高水平、风险偏好下降，或扩产后设备稀缺程度缓解，都可能压缩倍数。盈利增长并不能保证股价同步上涨。

相较上篇约154欧元，新价格降低了买入门槛；新指引也把原来FY28的集团14—16%利润率目标提前带到FY27。但模型原本就要为增长付费，不能因为看到一份强财报，就让价值无条件大幅上调。

集团还提出FY28—30年均税前FCF约150亿。燃机的长期服务、电网多年更新需求和风电减少亏损，共同构成路径，但目标仍需供应链、产能、客户融资和项目执行支持。

有两项可比性需要保留。FY27利润率包含品牌许可费，FY30目标不含；如果剩余费用改列特殊项，经济成本不会因此消失。工业转型业务未来分离又会改变报表范围。当前模型维持现有业务口径，不另免费增加出售收入或保留股权；最终条款明确后要重建。

采用目标低端核对：收入700亿、特殊项前率20%，减PPA和持续特殊费用各2亿，加净财务收益2亿，税率25%、少数股东利润7亿，归母约96.5亿。股数固定8.55亿，EPS约11.29欧元。

| 2030年末估值条件 | 未来条件性股价 | 按11%要求回报折现并加期间股息现值 |
| --- | ---: | ---: |
| 16倍PE | 约181欧元 | 约131欧元 |
| 20倍PE | 约226欧元 | 约161欧元 |

折现期限约3.89年；期间每股股息采用2.30、2.80、3.60、4.50欧元的研究假设，合计13.20欧元。只有首笔2.30是已提出的股息方案，其余不是公司承诺。

这是一项目标兑现后的退出估值核对，**不是完整DCF，也不是今天181—226欧元的目标价**。它显示约129欧元支持长期持有的可能路径，也显示未来倍数回落会消耗多少增长价值。未提前假设全部回购缩股，未将税前FCF直接永久资本化，也未把拆分价值重复加入。[公司长期目标](https://www.siemens-energy.com/global/en/home/press-releases/siemens-energy-reports-record-year-and-sets-ambitious-targets-fo.html)。

AI基础设施的物理瓶颈会给设备商带来订单和议价机会，也可能推迟客户项目。总积压中，公司标记的数据中心相关约150亿、占约9%，服务积压约710亿，需求来源较广；但9%不等于集团全部间接AI敏感度，燃机和电网仍可能同时受客户资本开支周期影响。

因此，最有价值的能力是把紧缺期订单可靠交付，再将装机转成长期服务；最需要警惕的情形，是市场把今天的设备紧缺与提价永久外推。

## 持有与新增资金，分别需要什么证据

约129欧元，已有持仓继续持有的经营依据较上季度更充分。新投入资金仍应留下价格余地，而不是单纯因为较高点跌得多就增加规模。

| 价格条件 | 本报告倾向 | 适用前提 |
| --- | --- | --- |
| 约125—130欧元 | 持有，新增资金保持克制 | 基准价值约145欧元，折价仍有限 |
| 约115—120欧元 | 更适合分批增加 | 下跌主要来自市场波动，经营假设保持 |
| 约112—116欧元 | 接近对本轮不同参考值的20%折让要求 | 情景参考约140、基准约145，均仍须兑现 |
| 约140欧元以上 | 新资金的估值余地明显收窄 | 需要新的盈利或风险改善证据 |

这些是有日期、附条件的判断，不是价格触发后的自动买入规则。需要持续核对的证据为：

1. **正式订单转化：**39GW预订是否按FY27安排转正；若持续推迟、取消增加或客户无法付款，应下调增长和现金预测。
2. **核心利润率：**燃机18—20%、电网21—23%的FY27指引是否维持；扩产费用、供应链或新单定价若使其下调，应重估，不能仅凭订单总量坚持原价值。
3. **Gamesa现金：**是否出现新的质量和项目损失，全年现金相对负15.8亿如何改善，FY28经营现金转正路径是否保持。
4. **预收与交付：**预收款正常化本身未必是坏事；若同时收入验收、利润和回款恶化，就不能继续用高峰FCF支撑价值。
5. **资本配置：**品牌转换、TI拆分税费、Siemens Energy India资本承诺及员工计划用股，是否侵蚀每股回报。

这次更新支持的是“经营兑现提高持有依据，较低价格改善新增资金回报条件”。目前约129欧元仍需要接受明显波动，115—120欧元会提供更好的容错空间。未来价值最终取决于交付、现金和每股收益，而非订单叙事本身。
